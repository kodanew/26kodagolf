# 2026 KODA·ARP 골프대회 모바일 초청장

GitHub Pages 배포용 최종본입니다.

## 구성
- `index.html` : 모바일 초청장
- `intro.mp4` : 인트로 영상
- `.nojekyll` : GitHub Pages 정적 배포 보조
- `README.md` : 배포 안내

## GitHub Pages 배포
1. GitHub에서 새 Public repository를 생성합니다.
2. 이 ZIP을 압축 해제합니다.
3. 안의 4개 파일을 저장소 최상단(root)에 업로드합니다.
4. 저장소에서 `Settings` → `Pages`로 이동합니다.
5. `Build and deployment`의 Source를 `Deploy from a branch`로 선택합니다.
6. Branch는 `main`, Folder는 `/(root)`로 선택하고 Save 합니다.
7. 잠시 후 Pages 화면에서 공개 주소를 확인합니다.

예시:
`https://YOUR-ID.github.io/koda-arp-golf-2026/`
